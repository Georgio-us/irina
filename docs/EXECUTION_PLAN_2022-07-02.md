# Execution Plan 2 июля 2022 года

> Статус на 9 июля 2026: реализовано / reference.
>
> План использовался для создания `/webinars/inner-state.html` как первого webinar detail/content template. Текущий статус вебинарных страниц и дальнейший порядок работ фиксируются в `SITE_STRUCTURE.md` и `CURRENT_ASSESSMENT_2026-07-05.md`.

Задача: создать новую страницу отдельного вебинара /webinars/inner-state.html как тестовый Content Template v1 для вебинаров.

Важно:

Не переделывать главную.
Не ломать текущие страницы программ.
Не переписывать дизайн-систему.
Использовать существующие CSS tokens, типографику, кнопки, контейнеры, отступы и стили сайта.
Страница должна ощущаться как premium content page, а не как лендинг программы и не как инфобизнесовая продажная страница.

Референс по ощущению: MasterClass / Netflix / premium webinar page.
Не копировать визуально сторонние сайты, но взять архитектуру:

сильная темная обложка;
крупное видео-превью;
короткое описание;
таймкоды / структура просмотра;
блок результата после просмотра;
витрина других вебинаров;
footer.

Страница должна быть универсальным шаблоном, который потом можно использовать для других вебинаров, медитаций, книги и отдельных материалов.

Технические требования:

Сделать отдельную страницу /webinars/inner-state.html.

Не ломать существующие страницы:

главная;
методология;
Mentor 28;
Продавай как звезда.

Использовать существующую дизайн-систему.

Если нужны новые классы — называть их универсально:

content-hero
content-intro
content-timeline
content-results
content-related
webinar-card
video-preview

Страница должна быть reusable content template.

Не добавлять FAQ, отзывы, “для кого”, длинные продающие блоки.
Это не product page, а content page.

Адаптив обязателен.

На мобильном:

hero складывается в одну колонку;
сначала видео, потом текст;
кнопки становятся удобными для нажатия;
timeline превращается в обычный вертикальный список;
results-сетка становится одной колонкой;
карточки вебинаров можно сделать в одну колонку или horizontal scroll.

Главная цель:

Создать страницу, которая выглядит как премиальная страница просмотра авторского вебинара: кинематографичная обложка, короткое объяснение ценности, структура просмотра и переход к другим материалам.
