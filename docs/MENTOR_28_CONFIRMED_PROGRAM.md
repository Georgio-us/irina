## 1. Принцип упаковки

На сайте программа обозначается как «4 учебных модуля + 4 живые встречи “Кофе с ментором”». Вместе они образуют восемь последовательных единиц программы:

1. четыре основных тематических модуля;
2. четыре живые встречи «Кофе с ментором».

Порядок:

> Модуль 1 → Кофе с ментором №1 → Модуль 2 → Кофе с ментором №2 → Модуль 3 → Кофе с ментором №3 → Модуль 4 → Кофе с ментором №4.

В русской версии используется название «Кофе с ментором». В украинской локализации используется «Кава з ментором».

## 4. Правила представления на сайте

Каждая из восьми единиц показывает только:

- тип;
- официальное название;
- один короткий вводный абзац;
- три укрупненные темы;
- один результат.

Полные перечни протоколов, практик, диагностик, трекеров, аудиопрактик и материалов не публикуются внутри карточек.

Под блоком используется один общий CTA:

> Получить подробную программу.

Текущая интерактивная верстка из восьми переключаемых состояний сохраняется. Это не восемь модулей: четыре состояния относятся к модулям, ещё четыре — к живым встречам. Для живых встреч вместо номера используется иконка чашки.
