# Дизайн-система и Руководство по верстке раздела «Библиотека знаний»

Этот документ содержит описание архитектуры верстки, дизайн-токенов (цветов, шрифтов, скруглений, отступов) и сетки, используемых в обновленном блоке табуляций раздела «Библиотека знаний» (`.courses`) на сайте. 

Документ создан для разработчиков и дизайнеров с целью сохранения преемственности стилей при дальнейшей доработке интерфейсов.

---

## 1. Сетка и Структура Лейаута (Grid & Layout)

В основе верстки лежит жесткая **12-колоночная сетка** с локальными адаптациями под каждый тип контента.

### Основные параметры сетки:
- **Ширина контейнера**: Макет зафиксирован в обертке `.page-wrapper` на ширине **`1440px`** с центрированием `margin: 0 auto`.
- **CSS Grid**: Элементы табуляций используют `display: grid; grid-template-columns: repeat(12, 1fr);`.
- **Межколоночный интервал (Gap)**:
  - Для блоков «Вебинары» и «Научная база»: `gap: 24px 20px` (строки / колонки).
  - Для блока «Книга»: `column-gap: 24px`.
- **Внутреннее выравнивание**: Большинство колонок деталей растягиваются по высоте контента обложек (`align-items: stretch`).

### Разметка по колонкам в табах:
1. **Авторские программы (`#grid-programs`)**:
   - Состоит из двух карточек, каждая занимает **6 колонок** (`grid-column: span 6`).
2. **Вебинары (`#grid-webinars`)**:
   - Главная обложка: **6 колонок** (`span 6`).
   - Детализация вебинара: **4 колонки** (`span 4` с 7 по 10 колонки). Колонки 11 и 12 остаются свободными для асимметрии.
   - Нижний ряд карточек: 4 карточки по **3 колонки** каждая (`span 3`).
   - Нижняя цитата: на всю ширину **12 колонок** (`span 12`).
3. **Книга (`#grid-books`)**:
   - Обложка книги: **6 колонок** (`span 6`).
   - Описание книги: **4 колонки** (`span 4` с 7 по 10 колонки).
   - Блок превью-карточек справа: **2 колонки** (`span 2` с 11 по 12 колонки).
4. **Научная база (`#grid-science`)**:
   - Обложка: **6 колонок** (`span 6`).
   - Детализация базы: **4 колонки** (`span 4` с 7 по 10 колонки).
   - Средний ряд (Cambridge CTA Banner): на всю ширину **12 колонок** (`span 12`).
   - Нижний ряд карточек: 3 карточки по **4 колонки** каждая (`span 4`).

## 2. Цветовая Палитра (Color Palette)

Вся цветовая палитра унифицирована на уровне глобальных семантических переменных в `:root` (в файле `style.css`):

```css
:root {
    /* Базовые цвета макета */
    --color-bg: #FBF7F6;            /* Основной фон страниц */
    --color-border: #EFE8E2;        /* Тонкие разделительные линии */
    --color-white: #FFFFFF;         /* Чистый белый для контрастных плашек и кнопок */

    /* Семантические цвета текста */
    --color-text-main: #333333;     /* Основной текст, крупные и средние заголовки */
    --color-text-muted: #666666;    /* Вторичный текст, описания, подзаголовки */
    --color-text-light: #999999;    /* Служебные тексты, копирайты, плейсхолдеры */

    /* Функциональные акценты (фиолетовая гамма) */
    --color-accent-text: #52236A;       /* Текстовые акценты, ярлыки, ссылки */
    --color-accent-text-hover: #3D1652; /* Состояние ховера для текстовых ссылок */
    --color-accent-ui: #4C224C;         /* UI элементы: кнопки, активные табы, иконки */
    --color-accent-ui-hover: #381838;   /* Состояние ховера для кнопок и UI элементов */
    --color-accent-light: #F5EBEF;      /* Мягкий фоновый оттенок (лиловый/розовый) */

    /* Премиальный золотой акцент */
    --color-accent-gold: #C5A880;       /* Золотые элементы, звезды, LUX-статусы */
}
```

### Принципы использования цветов:
- **`--color-text-main`**: Все крупные и средние заголовки (включая H1-H4) по умолчанию должны иметь этот цвет (без фиолетового окраса, если это не специальные выделения внутри заголовка).
- **`--color-accent-text`**: Используется точечно для привлечения внимания в текстах (например, тег `span` внутри заголовка, подписи разделов).
- **`--color-accent-ui`**: Используется для интерактивных элементов управления.
- **`--color-accent-gold`**: Эксклюзивный премиум-акцент (логотип-точка, тариф LUX Club, звездные рейтинги). Повсеместное использование не рекомендуется.

## 3. Типографика (Typography)

Используется сочетание антиквы для заголовков и гротеска для интерфейсного текста.

### Шрифтовые гарнитуры:
- **Serif (Заголовки)**: `'Playfair Display', Georgia, serif` (переменная `--font-serif`). Придает премиальный, классический вид.
- **Sans-serif (Интерфейс)**: `'Montserrat', system-ui, -apple-system, sans-serif` (переменная `--font-sans`). Читаемый и современный.

### Шрифтовая иерархия в Библиотеке:
- **Главные заголовки в табах (`.lib-title`)**: `26px` - `28px`, Serif, начертание `500` или `400`.
- **Подзаголовки/Метки категорий (`.lib-subtitle`)**: `10px` - `11px`, Sans-serif, начертание `700` или `800`, `text-transform: uppercase`, `letter-spacing: 0.15em`.
- **Названия карточек (`.science-card-title`, `.blog-card-title`)**: `14px` - `18px`, начертание `800` (Sans-serif) или `400` (Serif).
- **Основной текст (`.lib-desc`, `.science-card-desc`)**: `11px` - `13px`, Sans-serif, начертание `500` или `400`, `line-height: 1.4 - 1.55`.
Правило: сначала определяем **роль текста**, затем выбираем размер. HTML-тег (`h1`–`h4`) отвечает за семантическую структуру документа, а не за визуальный масштаб сам по себе.

### Гарнитуры и допустимые веса

- **Serif / editorial**: `'Playfair Display', Georgia, serif` (`--font-serif`). Используется для display-заголовков, заголовков разделов, содержательных карточек и цитат.
- **Sans / interface**: базово `'Montserrat', system-ui, -apple-system, sans-serif` (`--font-sans`). Manrope проходит отдельную проверку на главной как более мягкая альтернатива для интерфейса, labels, основного текста, метаданных и CTA.
- Загружаемые веса Montserrat: `300`, `400`, `500`, `600`, `700`. Вес `800` не использовать, пока он не добавлен в загрузку шрифта: сейчас браузер синтезирует его и создаёт нестабильный визуальный результат.
- Italic — смысловой акцент внутри editorial-заголовка или цитаты; не заменяет полноценный уровень иерархии.

### Целевая шкала ролей

Это проектная шкала для последующего внедрения. Значения намеренно сгруппированы: новые локальные размеры не добавляются, если роль уже существует.

| Роль | Гарнитура и вес | Desktop | Mobile | Межстрочный интервал | Где использовать на главной |
| --- | --- | --- | --- | --- | --- |
| `display` | Serif 400 | `clamp(40px, 3.33vw, 48px)` | 34–40px | 1.15 | Hero; максимум H1 — 48px даже на Full HD. |
| `heading-section` | Serif 400 | `clamp(30px, 2.22vw, 36px)` | 28–32px | 1.2 | «Что если проблема не в целях?», «Выберите свой следующий шаг», «Реальные люди». |
| `heading-content` | Serif 400–500 | `clamp(24px, 1.94vw, 28px)` | 24–28px | 1.25 | Блоки внутри раздела: Library, LUX, «Обо мне», контактный блок. |
| `heading-card` | Serif 400–500 **или** Sans 600 | `clamp(18px, 1.25vw, 22px)` | 18–22px | 1.35 | Названия editorial-карточек; выбор гарнитуры определяется типом карточки, не случайным селектором. |
| `label` | Sans 600, uppercase | 10–11px | 10–11px | 1.2 | Категория над заголовком: «Библиотека знаний», «Программы и продукты», «Контакты». Tracking один: `0.12em`. |
| `body` | Sans 400–500 | 15–16px | 14–16px | 1.6 | Основные описания, вступления, текст статьи. |
| `body-compact` | Sans 400–500 | 13–14px | 13–14px | 1.55 | Описания в карточках и списках, где пространство ограничено. |
| `meta` | Sans 500–600 | 10–11px | 10–11px | 1.4 | Автор, длительность, подпись, служебная информация. |
| `action` | Sans 600, uppercase | 11–12px | 11–12px | 1 | Кнопки и action-ссылки. Tracking один: `0.08em`. |

### Что не входит в обычную шкалу

- Названия на графических обложках программ и вебинаров — **cover display**. Их контраст, uppercase и размер зависят от изображения; их нельзя автоматически приравнивать к `heading-card`.
- Большие кавычки, цифры статистики и декоративные названия LUX — **accent display**, а не уровни заголовков.
- Поля формы, toast/модалки и видео-заглушки — UI-компоненты. Они используют `body`, `meta` и `action`, но не создают новые типографические уровни.

### Правила согласованности

1. Каждый текстовый селектор получает одну роль шкалы; локально можно менять только цвет, максимальную ширину или отступы, если этого требует композиция.
2. `label` и `action` не используют произвольные `font-size`, weight и letter-spacing. Отдельный визуальный стиль не создаётся для каждой секции.
3. `body-compact` допустим только внутри плотного компонента; текст раздела не уменьшается до карточного размера ради сохранения воздуха.
4. `heading-card` не должен конкурировать по масштабу с `heading-content`; если карточка требует большего акцента, это отдельный cover display-компонент.
5. Serif задаётся явно для editorial-ролей. Нельзя полагаться на случайное наследование от контейнера.
6. Sans использует три рабочих веса: `400` для чтения, `500` для смыслового акцента, `600` для labels и действий. `700` допустим лишь для короткого редкого акцента; `800` не используется.

### Эталоны главной для первой волны

| Роль | Эталонный элемент | Что сохранить при внедрении |
| --- | --- | --- |
| `display` | `.hero-title` | Спокойный Serif, один italic-акцент, много воздуха. |
| `heading-section` | `.selector-title`, `.testimonials-title` | Центрированный спокойный заголовок без декоративного перегруза. |
| `heading-content` | `.methodology-title`, `.lib-title`, `.about-title` | Редакционный характер и компактный ритм. |
| `label` | `.hero-label`, `.courses-subtitle`, `.lib-subtitle` | Короткая uppercase-подпись над смысловым заголовком. |
| `body-compact` | `.program-desc`, `.science-card-desc` | Хорошая читаемость в карточке без превращения текста в caption. |
| `action` | `.btn-primary`, `.text-link` | Сдержанный интерфейсный акцент; не соревнуется с заголовком. |

### Порядок внедрения

1. Сверить эту шкалу на desktop-главной с эталонными элементами.
2. Подобрать окончательные значения и mobile-границы для каждой роли на реальном рендере.
3. Ввести семантические CSS-токены ролей рядом с текущими переменными.
4. Переводить главную секциями, начиная с повторяющихся ролей `label`, `action`, `body-compact` и section headings.
5. После визуального QA переносить уже подтвержденные роли на каталоги, product/detail и статьи.

## 4. Скругления углов (Border Radii)

Скругления обеспечивают мягкость интерфейса и упорядоченность блоков:
- **`20px`**: Крупные внешние плашки и горизонтальные баннеры с эффектом стекла (например, `.hero-stats-banner`, `.not-alone-card`).
- **`16px`**: Крупные обложки и контейнеры (например, `.science-cover-wrapper`, `.science-cta-wrapper`, `.video-testimonials-container`, внешняя колонка `.lib-left-col`).
- **`12px`**: 
  - Карточки нижних рядов (вебинары, научные статьи, видеоотзывы `.video-review-thumb`).
  - Слайдер-карточки отзывов (`.testimonial-slider-card`).
  - Фоновые плашки цитат (`.lib-quote-box`, `.webinar-bottom-quote`).
  - Все кнопки действий и контурные кнопки на сайте (`.btn-lib-action`, `.btn-lib-outline`, `.btn-science-cta`, `.btn-video-more`, `.btn-banner-action`, а также кнопки в `.header` и `.hero`).
- **`8px`**: Внутренние интерактивные элементы меньшего размера (поля ввода форм, превью-карточки, иконки соцсетей на главном экране `.hero-socials a`).
- **`50%` (Круг)**: Круглые бэджи иконок (`.feature-icon-circle`, `.stat-circle-icon`, `.banner-icon-circle`), кнопки управления плеером, круглые кнопки-стрелки (`.science-card-arrow`, `.slider-arrow`).

## 5. Отступы и Внутренние Расстояния (Paddings & Gaps)

Для сохранения чистоты макета все элементы внутри текстовых блоков выстроены через Flexbox с фиксированными промежутками:
- **Центральное управление отступами**: Все текстовые группы (Subtitle + Title + Desc + Quote/Buttons) обернуты в класс контента (например, `.science-details-content`) с правилом `gap: 12px`. Это исключает использование хаотичных `margin-bottom` у дочерних тегов.
- **Внутренние отступы баннеров**:
  - Баннеры CTA: `20px 32px` или `24px 32px` для сбалансированного распределения пространства.
  - Цитаты: `24px 32px`.
  - Карточки с фоновыми изображениями: `24px` со всех сторон.
- **Вертикальные линии-разделители**:
  - В блоке цитат Hero (`.hero-quote-card`): левая рамка `border-left: 1px solid rgba(255, 255, 255, 0.25)` с отступом `padding-left: 20px` формирует четкую вертикальную линию разграничения на фоне темного изображения.
  - В баннере преимуществ (`.banner-separator`): вертикальные разделители высотой `40px` с цветом `rgba(76, 34, 76, 0.1)`.

## 6. Анимации и Микро-взаимодействия (Animations & Transitions)

Для премиального ощущения от интерфейса добавлены мягкие ховер-эффекты:

### 1. Эффект приближения обложек (Zoom):
При наведении на карточки или блоки обложек фоновое изображение плавно масштабируется:
```css
.science-card-img, .science-cover-image {
    transition: transform 0.6s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
.science-card-item:hover .science-card-img {
    transform: scale(1.04);
}
```

### 2. Ховер кнопок-стрелок:
Белые круглые стрелки на карточках при наведении инвертируют цвета и слегка увеличиваются в размере:
```css
.science-card-arrow {
    transition: all 0.3s ease;
}
.science-card-item:hover .science-card-arrow {
    background-color: #4C224C;
    color: #FFFFFF;
    transform: scale(1.08);
}
```

### 3. Интерактивные кнопки плеера и вкладок:
- Вкладки верхнего меню плавно подчеркиваются линией при фокусе/клике.
- Кнопки плеера имеют ховер с легким изменением прозрачности оверлея или фонового тона.

## 7. Технические Примечания по Верстке
- **Адаптация обложек**: Все изображения обложек должны использовать свойство `object-fit: cover; width: 100%; height: 100%;` внутри фиксированных по высоте оберток. Это защищает дизайн от искажения пропорций картинок.
- **Отсутствие `!important`**: Верстка выполнена чисто, за счет вложенности селекторов и локального переопределения переменных, что гарантирует легкую поддержку.
- **Сброс кэша стилей**: При внесении изменений в файлы стилей не забывайте обновлять версию в подключении файла в `index.html` (например, `style.css?v=14`).
